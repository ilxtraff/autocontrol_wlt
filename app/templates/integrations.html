Интеграции

Автоконтролю нужны две вещи: ключ Keitaro, откуда берётся статистика, и токен социального аккаунта Facebook, которым выключаются и включаются адсеты. У кабинета обязательно должна быть таймзона — по ней отсчитываются сутки.

Keitaro

«Поле адсета» — тот sub_id, на который в настройках Keitaro замаплен параметр adset_id={{ "{{adset.id}}" }} из ссылки. Номер у всех свой; ошибётесь — движок увидит нули и никого не выключит. Не уверены — python -m app.cli find-field --account <ID> подберёт сам.

Социальные аккаунты Facebook

Вставьте мультитокен — из него разберутся токен, куки, прокси и user-agent. Запросы пойдут через прокси аккаунта: с чужого IP Facebook быстро выдаёт чекпоинт. Куки нужны, чтобы перевыпустить токен без вашего участия, когда он протухнет. Секреты хранятся в базе зашифрованными. Формат — любой распространённый: токен|куки, JSON или base64-строка из антидетект-браузера (куки массивом внутри).
Прокси: host:port, host:port:user:pass, user:pass@host:port — это HTTP. Для SOCKS схему нужно указать явно: socks5://user:pass@host:port.
